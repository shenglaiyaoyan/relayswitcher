② Provider 编辑页 —— 解决“拉回 20 个模型要一个个填参数”

你的操作顺序：填好 Base URL 和 API Key → 点 ③“拉取” → 拉回来的模型自动按名字认出是哪一系（Claude / GPT…）→ 加进来的模型参数已经自动填好 → 想统一改几个，就 ⑤ 勾选它们，⑥ 选模板点“套用”。

  1. 1小眼睛：点一下 API Key 显示明文，再点隐藏。
  2. 2拉取结果：每个模型后面写着认出的系列，如“gpt-6.1-sol | GPT”；认不出的写“未匹配”，需要你手填或手选模板。
  3. 3拉取按钮：用上面填的地址和 Key 拉模型列表（原来就有）。
  4. 4搜索 + 筛选：模型多时输入名字找，或点“Claude / GPT / Gemini”只看这一系。
  5. 5勾选框：勾上几个模型（图里勾了 3 个）。
  6. 6批量套用栏：勾选后出现。选“按名称自动匹配”或指定某个模板，点“套用”，3 个模型的参数一次填好。
  7. 7右侧：当前选中那个模型的参数，详细见下面的图 ③。

③ 单个模型参数 —— 解决“某一个模型想换模板 / 微调”

你的操作顺序：左边点一个模型 → 右上 ① 下拉选模板，点“套用”，下面所有参数被填好 → 哪项不合适直接改（③④⑤⑥都能改）→ 改过的项会标“已修改” → 最后底部统一保存。

  1. 1参数模板：下拉选模板 → 点“套用”填入；“存为新模板”把这个模型现在的参数存成新模板，下次复用。
  2. 2来源说明：告诉你这些参数是从哪个模板来的；之后改模板不会偷偷改这个模型。
  3. 3已修改：你手动改过的项（例：最大输出从 128000 改成 64000）会带这个小标记。
  4. 4四个开关：推理 / 附件 / 工具 / Temp，套用后仍可随便开关。
  5. 5输入 / 输出模态：五个和三个选项一直都在，亮的是选中，点一下切换。
  6. 6思考档位：点档位设为默认，× 删除，右边输入框加新档位。
  7. 7示意小框：只是演示 ① 下拉展开后长什么样（上面是推荐的，下面是全部模板），实际不会出现在这个位置。
