## 布局

- 页头：标题「ChatGPT」+ 一句说明；右侧刷新、账号管理、ChatGPT 设置三个图标按钮。Codex 目录挪到右侧状态里。
- 竞品工具提醒：一条细横幅（检测到 X 正在运行，可能覆盖配置 · 知道了）。
- 主体两栏（约 55% / 45%）：
  - 左上「切换」卡：账号下拉、中转站下拉、模型目录分段（官方目录 · N 模型 / 中转目录 · N 模型）、上下文窗口分段（272K / 372K / 872K）+ 自定义输入；全宽主按钮「立即切换」+ 说明「自动备份当前配置，完成后可回滚」；分隔线下「切换流程」横向五步：备份当前配置 → 写入登录态 → 流量指向中转站 → 部署模型目录 → 校验。
  - 左下「最近备份」卡：最近 3 条（时间 · 原因 · 说明），第一条「一键回滚」（与原行为一致，直接回滚），其余「回滚」需确认。
  - 右侧「当前状态」卡占满高度，分三组：登录态（账号 + OAuth、计划、令牌：access / id_token）、流量出口（中转站名 + URL、延迟）、Codex（模型、目录、窗口、Codex 目录）。账号、中转站行可点击跳到对应管理页。
- 去掉原「三张状态卡 + 01/02/03 步骤 + 大白按钮 + 终端日志框」。

## 流程进度

- 五步状态由 `onSwitchStep` 事件推导：`备份当前配置`、`写入登录态*`、`流量指向中转站`、`目录生成`→部署模型目录、`校验完成`；对应步骤成功为完成、失败为出错；切换中第一个未完成步骤为进行中。
- 竞品检测、中转站预检、token 预刷新、会话迁移等其它步骤不丢：切换后在流程下方显示可折叠「详细日志」（默认展开最近一次结果的失败项）。
- 完成/失败提示保留（toast + 流程状态）。

## 保持不变

- 切换、Codex 运行拦截弹窗（手动退出 / 仍要切换 / 帮我关闭并切换）、回滚、竞品检测、默认值同步、demo hash（`#dash-demo-warn` / `#dash-demo-modal`）。
