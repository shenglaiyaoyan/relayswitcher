# OpenCode 编辑页重做（表格 + 右侧抽屉）— 设计

日期：2026-10-29 · 状态：用户已确认（`designs/byok-opencode/C-final.html`，布局 C）

## 背景

v1.15.0 实际使用反馈：编辑页视觉不舒服、过于繁琐；整页滚动，连接区占半屏，参数被保存栏挡住，保存栏下方大片留白（根因：`.oc-workspace` 用 `calc(100vh - 108px)` 加负边距，与 `.main` 内边距不匹配，没有撑满窗口）。

本项是三个子项目中的第 1 个（之后：ChatGPT 页重设计、浅色皮肤）。

## 布局

- 编辑页占满主区域：`.main` 在编辑页下不留内边距、不滚动；只有表格和抽屉内部滚动；保存栏贴窗口底部。
- 顶部：`← Provider 列表`、小标题「OpenCode 提供商 / 新建 Provider」、显示名称（标题位置的行内输入框）、右侧「拉取模型」。
- 连接条（一行）：协议（紧凑下拉）、Base URL、API Key（掩码 + 眼睛）、Provider ID，均为行内输入，失焦提交（沿用 DraftTextInput 和 flush 机制）。
- 主体：全宽模型表格 + 右侧 440px 参数抽屉；抽屉关闭时表格占满。
- 保存栏：左「● 有未保存的修改」，右「取消」「保存并写入 OpenCode 配置」。

## 模型表格

- 工具条：搜索（ID/名称）、「N 个模型」、「批量」、「+ 手动添加」。
- 列：模型 ID（等宽，默认模型带「默认」小标）、名称、模板（小标签，未匹配为虚线）、上下文、输出、默认档位、能力（推/附/工/T 四个点，亮=开）。
- 点行打开该模型抽屉；选中行左侧金色竖线。
- 批量模式：每行出现深色复选框，表头复选框全选当前可见行；抽屉收起；表格底部批量栏「已选 N 个 · 模板（按名称自动匹配/指定）· 套用 · 取消」。退出批量清空选择。

## 拉取模型弹层

- 点「拉取模型」后在按钮下方锚定弹层（非遮罩弹窗）：标题「从 /v1/models 拉取到 N 个」，每行复选框 + 模型 ID + 匹配模板标签；已添加的置灰并标「已添加」；底部说明「加入时自动套用匹配模板」+「加入 N 个」。
- 加入的模型按匹配模板自动套用（未匹配用默认空白参数）；点外部或 Esc 关闭。
- 去掉原侧栏芯片区。

## 参数抽屉

- 头部：显示名称 + 等宽 ID；「模板 · X ▾」菜单（列出模板，匹配的标“推荐”，点击即套用；末项「存为新模板」）；「设为默认」星标；关闭 ×。
- 来源说明一行（来自 X 模板 · 时间）。
- 分组：基本（ID、名称、上下文、最大输出）→ 能力（四开关一行）→ 模态（输入/输出 5 个选项）→ 思考档位（点选默认、× 删除、行内「添加档位」输入 + 添加按钮）。
- 「已修改」标记保留；底部「删除此模型」（确认后删除）。
- 原编辑器底部的「默认模型」下拉移除，改由抽屉星标设置。

## 颜色

新写的样式只用 CSS 变量（新增 `--surface`、`--surface-2`、`--hover`、`--selected`、`--accent`、`--accent-strong`、`--on-accent`、`--line-soft`、`--input-bg`），为子项目 3 的浅色皮肤做准备；本项不加切换开关。

## 不变

- 保存/写入规则、flush 机制、模板逻辑（templates.mjs）、未保存离开确认。

## 测试

- 源码断言更新：撑满布局、批量复选框只在批量模式、拉取弹层、抽屉模板菜单、默认星标、移除默认模型下拉。
- 全量单测 + smoke；隔离环境截图核对深色主界面、批量、拉取弹层。
