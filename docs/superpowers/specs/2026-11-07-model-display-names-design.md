# 模型显示名自动美化 — 设计

日期：2026-11-07 · 状态：用户已确认（替换工作区里未提交的半成品实现）

## 目标

OpenCode 编辑页里新加模型的显示名不再照抄 ID，而是生成 `Claude Opus 5.5`、`GPT 6 Astra` 这样的格式。模型 ID 不变。

## 规则 `prettifyModelName(id)`

1. 取最后一个 `/` 之后的部分（`org/claude-opus-5` → `claude-opus-5`）。
2. 按 `-`、`_`、空格切段；丢掉 8 位日期段（`20250929`）。
3. 品牌与版本粘连且字母 ≥3 个时拆开：`qwen3.8` → `qwen` `3.8`。
4. 相邻的 1–2 位整数段合并为点分版本：`5` `5` → `5.5`。
5. 每段格式：
   - 品牌表：GPT、Claude、Gemini、DeepSeek、GLM、Kimi、Qwen、Grok、MiniMax、Mistral、MiMo、Llama、Gemma、Codex、OSS；
   - 数字版本原样（`6.1`）；
   - 1–2 个字母 + 数字转大写字母（`v4`→`V4`、`k3.1`→`K3.1`、`m3`→`M3`）；
   - 数字 + b/k/m 规模后缀转大写（`120b`→`120B`）；
   - 其它全小写单词首字母大写，原本含大写的保持（首字母大写）。
6. 空格连接；空 ID 返回空串。

## 生效范围

- 新模型：`newModel(id)` 显示名用美化结果（拉取加入、手动添加）。
- 手动添加后填 ID：显示名为空、等于旧 ID 或等于旧 ID 的美化名时，随 ID 自动更新；用户改过的名字不动。
- 已有模型：表格工具条出现「整理名称（N）」，只处理显示名为空或等于 ID 的模型。
